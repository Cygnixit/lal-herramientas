Guía de Aegis Exposure Sheet

Versión 0.1.0 · Recurso del episodio LAL-T1-E01 (Atlas v0.2.3).

En una frase

Organiza señales externas observadas manualmente y compáralas con el inventario autorizado de tu organización.

Cómo empezar

  1. Abre la herramienta en tu navegador, o descarga su HTML para trabajar sin conexión. No requiere instalar software.
  2. Escribe el dominio que administras o estás autorizado a revisar y describe el alcance.
  3. Registra manualmente DNS, correo, CT, TLS, HTTP u otra señal, su fuente y fecha; usa Cargar ejemplo ficticio para practicar.
  4. Contrasta cada registro: expectativa, propietario, justificación, estado y evidencia para validar.
  5. Pulsa Guardar hoja · JSON para conservarla; importa el archivo cuando quieras continuar.
  6. Exporta CSV opcional y revisa los datos antes de compartirlos.

Significado de estados

Sin cotejar: aún no comparada. Coincide: coincidencia declarada por el operador. Por explicar: discrepancia pendiente; no indica intrusión. No verificable: evidencia insuficiente.

Precauciones

No hay escaneo ni peticiones automáticas de infraestructura; los datos introducidos no demuestran vulnerabilidades. CT es histórico. No hallar un selector DKIM cualquiera no demuestra DKIM ausente. Una cabecera Server no acredita versión ni CVE.

No introduzcas contraseñas, tokens ni datos personales. Protege los archivos exportados.

Privacidad

No se envían las observaciones a servidores y no hay guardado automático. CSV incluye mitigaciones parciales de fórmulas, no garantía universal entre lectores ni tras reexportar.
